## Fixes

The achievement garden has a valid labelled group role. Removed the global
rule forcing every `small` element to a pale color; corrected Kids card,
selected game, story, paragraph and consent text contrast. Game selection
and builder occupy the available section width. Food API fallback now
includes English names, and Kids categories have Arabic labels.

## Re-running browser QA

Install `playwright` and `axe-core` in the QA environment, install Chromium,
start the production build, and run `node scripts/kids-browser-qa.cjs`.
Default URL: `http://127.0.0.1:3001`. Optional environment variables:
`BASE_URL`, `PLAYWRIGHT_MODULE`, `AXE_PATH`, `QA_CHROMIUM_PATH`,
and `QA_SCREENSHOTS`. Results are written to `qa-results.json`.

## Limits

Local browser tests exercise guest persistence and unavailable database
fallbacks. Real authenticated account persistence is not verified because
no test account was supplied. Automated accessibility checks do not replace
an assistive-technology user evaluation. Existing external photography was
not replaced; its availability depends on the external host.

The Vercel configuration disables automatic Git deployments only for the
integration branch so one explicit production release can be requested.
Production readiness and live verification must be recorded after the
deployment completes; this report alone does not assert publication.
